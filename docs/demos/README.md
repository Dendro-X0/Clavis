# Demo recordings

Short GIF walkthroughs for the [README](../../README.md) and [features guide](../features.md). Re-record when a visible flow changes materially.

| File | Suggested caption |
|------|-------------------|
| `search.gif` | Command palette — search entries, jump to settings sections and vault views |
| `import-files.gif` | Import credentials — drag-and-drop creates a workspace |
| `appearance-settings.gif` | Appearance — light/dark theme, Seafoam/Graphite skins, list vs grid |
| `keyboard.gif` | Keyboard — shortcuts help, list focus, remap in Settings |
| `delete-recycle-bin.gif` | Recycle bin — soft delete, restore, or purge entries |

## Re-recording tips

- Unlock a vault with sample entries so search and palette have content.
- Use a consistent window size (~1280×800) for readable GIFs.
- Prefer 8–15 s loops; crop to the relevant panel.
- Keep secrets fictional (demo accounts only).
