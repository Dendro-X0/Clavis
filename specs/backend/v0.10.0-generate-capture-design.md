# Design — v0.10.0 generate, capture & soft-delete

**Status:** done (v0.10.0)  
**Band:** v0.10.0  
**Owners:** `vault-core` (generator + trash lifecycle), `clavis-shell` (IPC), `apps/web` (UI)  
**Depends on:** v0.9.0 mobile installers (or can overlap only if maintainer unblocks — default: after 0.9.0)  
**Umbrella:** Post-0.9.0 friction killers + trust hygiene (`docs/roadmap.md`)

## Goal

Cut daily friction **without** OS window injection: password generator, clipboard-aware quick-add, and soft-delete / recycle bin inside the vault.

## Non-goals

- Autotype / URL match (v0.12)
- Password health / HIBP (v0.11)
- Attachments, snapshots, structured notes (v0.13)
- Network of any kind; keep `allowNetwork` default off

## Features

### 1. Password generator

| Piece | Contract |
|-------|----------|
| Presets | e.g. **Strong** (long random), **Passphrase** (pronounceable words), **PIN** (digits) |
| Controls | length / word count, charset toggles (avoid ambiguous chars optional) |
| Apply | “Use in editor” fills password field; clear generator plaintext from UI on apply / dismiss / lock |
| History | **Session-only** ring of last N generated strings for this unlock (default N≤5); wiped on lock — **not** persisted in `vault.km` in v0.10 |

IPC sketch: `generate_password(options) -> string` (or return + immediate scrub on drop in Rust); UI never logs results.

### 2. Quick-add from clipboard

| Piece | Contract |
|-------|----------|
| Triggers | Palette / empty-state / New menu: “New from clipboard” |
| Heuristics | `otpauth://…` → draft with `otp_secret`; high-entropy / password-like → draft password; labeled multi-line paste (user/pass) when parseable |
| Confirm | Always open editor draft — **no** auto-save |
| Fail closed | Ambiguous clipboard → toast “nothing useful” / open blank new entry |

Shell: `clipboard_read_for_quick_add` only while unlocked; scrub buffer after parse.

### 3. Soft-delete / recycle bin

| Piece | Contract |
|-------|----------|
| Model | `Entry.deleted_at: Option<DateTime>` (or tombstone list); hidden from default lists/search |
| Restore | Recycle bin UI → clear `deleted_at` |
| Purge | Settings: retain N days (default e.g. 30); purge on unlock/save or explicit “Empty bin” |
| Export | Encrypted Clavis backup **includes** trash unless “exclude deleted” checked; CSV export **excludes** deleted by default |
| Lifecycle owner | **`vault-core` only** — one trash path (no parallel UI-only hide) |

## Threat / hygiene notes

- Generator output is a secret until saved or discarded — same scrub rules as passwords.
- Quick-add must not leave clipboard contents in React state after editor mount.
- Soft-delete is not secure erase until purge; document that trash still decrypts while vault unlocked.

## Proof plan

| Layer | Check |
|-------|--------|
| L1 | `cargo test -p vault-core` (generator entropy smoke, soft-delete filter/purge) · web `tsc` |
| L2 | IPC: generate → apply → lock clears UI; quick-add otpauth draft; delete → bin → restore → purge |
| Claim | **Implemented** only with L1+L2; not “secure wipe” beyond existing vault crypto |
