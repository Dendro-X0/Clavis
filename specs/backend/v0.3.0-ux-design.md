# Design — Clavis v0.3.0 UX

**Status:** approved for implementation  
**Owners:** `clavis-shell` (settings + icons IPC), `apps/web` (UI)

## Scope

1. Command palette: switch workspace; copy login / user / pass for entries  
2. Clipboard clear countdown toast  
3. Pinned workspaces in sidebar (`pinnedWorkspaceIds` in config)  
4. Offline-safe entry icons (lettermark + optional fetch → `data/icons/`)  
5. Version bump to **0.3.0**

## Settings additions (`data/config.json`)

| Field | Type | Default |
|-------|------|---------|
| `pinnedWorkspaceIds` | `string[]` | `[]` |
| `fetchFavicons` | `boolean` | `false` |

## Icons

- Path: `{data_dir}/icons/{sanitized_host}.ico` or `.bin` (raw bytes)  
- Commands: `read_entry_icon(host)`, `fetch_entry_icon(host)` (no-op if `fetchFavicons` false from UI; UI gates fetch)  
- Lettermark always rendered client-side from host/title first letter
