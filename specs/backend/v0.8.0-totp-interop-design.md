# Design — Clavis v0.8.0 TOTP & import interop

**Status:** done (impl; version bump pending band close)  
**Owners:** `crates/vault-core` (totp + CSV), `crates/clavis-shell` + `apps/web`  
**Depends on:** v0.7.0 shipped

## Goals

1. First-class `otp_secret` on `Entry` (Base32 / otpauth); offline TOTP SHA-1 / 6 digits / 30s.
2. UI: edit seed, live code, Copy code, Copy login → user → pass → code when TOTP set.
3. CSV: Bitwarden / KeePassXC / browser-style headers map `totp` / `login_totp` / `otp` into `otp_secret`.

## Non-goals

Sync, autotype, HOTP, custom algorithms UI, QR camera, store signing.

## Model

```text
Entry.otp_secret: String  // empty = none; scrubbed on lock
EntrySummary.has_otp: bool  // never expose seed in lists
```

## API

- `entry_totp_code(id) -> { code, secondsRemaining }`
- Upsert/get include `otpSecret`

## CSV column mapping (v0.8.0)

| Source | Title | User | Password | URL | TOTP |
|--------|-------|------|----------|-----|------|
| Generic | title/name | username/email | password | url | totp / otp / otpauth |
| Bitwarden | name | login_username | login_password | login_uri | login_totp |
| KeePassXC | Title | Username | Password | URL | TOTP / otp |

TOTP cells may be raw Base32 or `otpauth://totp/...` URIs.
